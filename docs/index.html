What can you build?

From ETS project data to developer workflows.

This is a headless library, not a one-click ETS desktop replacement. These are practical directions for using and extending the published packages.

01

Recognize device functions

03

Plan group addresses

Use and improve engineering planning and validation primitives before introducing changes into a real installation.

Run it. Test it. Improve it.

Explore the TypeScript packages and SDK, then run the existing verification suite locally with Node.js 22.6 or newer.

Quick start
git clone https://github.com/fwelpo3/knx-universal-open.git
cd knx-universal-open
npm ci
npm run verify

Runs TypeScript type checks, characterization tests and package-boundary checks. Development source only; no published npm release yet.
