# Contributing

Welcome, KNX integrators, developers, maintainers and smart-building enthusiasts.

Start with the [README](README.md), [architecture](docs/ARCHITECTURE.md) and [roadmap](docs/ROADMAP.md). Open an issue before major architectural changes.

## Contribution standards

- Keep code headless, testable and modular.
- Add tests for functional changes.
- Describe recognition evidence and ambiguous cases.
- Document input and output contracts.
- Submit synthetic or explicitly redistributable test data only.

**Do not submit** customer ETS projects, keys, licensing information, proprietary binaries, decompiled third-party source, or manufacturer data without permission.

[Open a collaboration issue](https://github.com/fwelpo3/knx-universal-open/issues/new). Discord and GitHub Discussions links will be added once configured.
